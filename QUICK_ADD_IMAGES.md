# Quick Guide: Add Real Equipment Images in 5 Minutes

## Fastest Way to Add Images (Using Free Stock Photos)

### Step 1: Download Images (2 minutes)

Go to these free stock photo sites and download equipment images:

**Option A: Unsplash (Recommended)**
1. Visit: https://unsplash.com/s/photos/backhoe-loader
2. Search for each equipment type:
   - "backhoe loader"
   - "wheel loader"
   - "excavator"
   - "skid steer"
   - "telehandler"
3. Download high-resolution images (click download → Original size)
4. Save them with the exact names listed below

**Option B: Pexels (Alternative)**
1. Visit: https://www.pexels.com/search/construction%20equipment/
2. Download free images
3. Rename to match file names below

**Option C: Pixabay (Alternative)**
1. Visit: https://pixabay.com/images/search/construction%20equipment/
2. Download free images
3. Rename to match file names below

### Step 2: Optimize Images (1 minute)

1. Go to: https://tinypng.com
2. Drag and drop all your downloaded images
3. Download the optimized versions
4. This reduces file size while maintaining quality

### Step 3: Rename & Place Files (2 minutes)

Rename your images to these EXACT names (case-sensitive):

```
jcb-3dx-super.jpg
cat-416f2.jpg
case-580n.jpg
volvo-l120h.jpg
cat-950m.jpg
komatsu-wa380.jpg
bobcat-s570.jpg
cat-259d3.jpg
jcb-540-170.jpg
manitou-mlt735.jpg
cat-d6t.jpg
jcb-457zx.jpg
```

Then copy them to:
```
/Users/bhaeesma/Desktop/adnax/public/equipment/
```

### Step 4: Refresh Browser

1. Go to: http://localhost:3000/equipment
2. Press Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows) to hard refresh
3. Images will appear!
